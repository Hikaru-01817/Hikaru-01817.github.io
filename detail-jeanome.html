View Site

概要

服の記録とリメイクの過程を「遺伝子」として可視化するWebサービスです。GitHub PagesではPHPやMySQLを公開できないため、現在はデモサイトとして公開しています。

制作目的

リメイクされた衣服がどのような過程を経て作られたのかを、Web上で分かりやすく見られるようにすること。

担当範囲

Webサイトの構成、デザイン、コーディング、公開作業など制作全般を担当しました。

使用技術

  • PHP
  • CSS
  • JavaScript
  • MySQL

工夫した点

シンプルかつ物語性を感じるデザインをテーマに、素材の質感や雰囲気が伝わるように構成しました。

学んだこと

Webサービスとして見せるためには、デザインだけでなく、情報の流れや公開方法も考える必要があると学びました。
