概要

テトリス風モードとぷよぷよ風モードを選択できるブラウザゲームです。ランキング、ルール説明、サウンド、スマホ操作にも対応しています。

制作目的

AIを活用しながら、PCとスマホの両方で手軽に遊べるブラウザゲームを制作すること。

担当範囲

企画、画面構成、UI調整、ゲーム画面制作、動作確認、公開。

使用技術

  • HTML / CSS
  • JavaScript
  • AI Tools（Gemini Pro, ChatGPT Plus, Codex）
  • GitHub Pages

工夫した点

PCとスマホの両方で遊びやすくなるように、操作ボタンやルール説明、ランキングなどを整理しました。

学んだこと

AIを活用して制作する場合でも、最終的な遊びやすさや見やすさは自分で確認して調整する必要があると学びました。
