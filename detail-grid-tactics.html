Browser Game / Strategy

Grid Tactics

3×2の盤面にユニットを配置し、攻撃や効果カードを使って戦うWebカードゲームです。

Play Game

概要

3×2の盤面でユニットを配置し、ユニットやスペルを駆使して戦うWebカードゲームです。現在はPCブラウザ向けで、スマホ表示には対応していません。最終的にはUnityで再実装予定です。

制作目的

ChatGPT PlusとCodexを活用し、企画から実装までブラウザゲームとして形にすること。

担当範囲

企画、ゲーム画面設計、カード画像や背景画像の準備、実装、公開。

使用技術

  • HTML / CSS
  • JavaScript
  • AI Tools（ChatGPT Plus, Codex）
  • GitHub Pages

工夫した点

カードのイラストとフレームを分けて制作し、後から合体させることで、フォーマットはそのままに、カードの種類を増やしやすくしました。また、盤面・カード・情報表示が分かりやすくなるように整理しました。

学んだこと

ゲーム制作では、見た目だけでなく、ルールの分かりやすさや操作しやすさが重要だと学びました。
